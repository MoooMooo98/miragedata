# SpaceX Super Heavy — Visual Reference Guide

Three user-provided images were supplied in the ChatGPT conversation (2026-11-12). Their binary JPEG files are **not yet committed** to this repository. Do not treat this guide as the photographs themselves.

## Reference A — Wide cinematic return
Vertical booster above coastal launch tower at sunset; distant ocean, warm horizon, large smoke cloud and narrow engine plume. Use as a mood/composition reference, not as proof of exact booster positions.

## Reference B — Tower close-up
Booster alongside launch tower at sunset, with dark lattice structure, mechanical arms, engine plume and warm smoke. Study tower-to-booster scale and framing.

## Reference C — Catch approach
Close view of metallic booster with grid fins, descending near the tower catch arms, with bright engine exhaust. Study brushed stainless-steel surface and relative arm geometry. Reference image may contain apparent fire/smoke on the side of the booster; do not assume this is normal operating behavior.

## Accuracy and rights
These are visual references, not validated technical drawings. Verify Super Heavy proportions, engine configuration and Mechazilla arm geometry against credible technical sources. Do not reuse images in a published video without confirming permission/licensing. Never claim an image file is available in `/references/spacex/` until it is actually committed.

## Workflow
Use the existing repository and skills. Audit assets and scripts first. Build one high-quality hero still of the booster, tower, and catch arms; inspect geometry, lighting and VFX. Stop for approval before full animation. No audio tracks are required.
